## 📌 Sobre o Projeto

Este é meu portfólio pessoal, desenvolvido com **HTML puro, CSS e JavaScript vanilla** — sem frameworks, sem dependências. O objetivo foi criar uma experiência visual elegante, rápida e responsiva que reflita minha identidade como engenheiro de software backend.

> Design minimalista com tema escuro, tipografia refinada e animações suaves de entrada e scroll.

## ✨ Funcionalidades

- **Navbar com glassmorphism** — backdrop-filter blur + encolhe ao rolar a página
- **Animações de entrada** — elementos surgem com `fadeUp` escalonado no carregamento
- **Reveal on scroll** — seções animam ao entrar na viewport via `IntersectionObserver`
- **Foto com moldura decorativa** — borda vermelha que se move no hover
- **Cards de projetos** — linha inferior que desliza, numeração editorial e links animados
- **Design responsivo** — adaptado para mobile e tablet
- **Scrollbar customizada** — vermelho `#f9004d` combinando com o tema

## 🎨 Design System

| Token | Valor | Uso |
|-------|-------|-----|
| `--red` | `#f9004d` | Cor de destaque principal |
| `--black` | `#0a0a0a` | Background base |
